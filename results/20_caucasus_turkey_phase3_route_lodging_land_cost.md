# 20｜ジョージア＋トルコ Phase 3（陸路・宿・生活費）

実行日: 2026-08-10

## 結論
航空券Phase 2の骨格を維持し、現地は「Tbilisi → Kazbegi → Kars → Cappadocia → Istanbul」の若者向け陸路ルートを本線にする。

Azerbaijanは2026-05-26に6年ぶりのBaku→Tbilisi旅客列車が実際に到着したが、2026-08-10現在、Georgian Railwayの公開General ScheduleのInternational Train欄にはTbilisi–Yerevanしか掲載されず、Azerbaijan Railwaysの現行公開route/scheduleにもBaku–Tbilisiが定期便として表示されない。
→ 卒業旅行の確定旅程にはまだ組み込まない。定期運行が確認できたらBaku追加を再検討。

## 推奨ルート骨格
- 10/13 Guangzhou → Tbilisi
- Tbilisi 旧市街・硫黄浴地区・市場
- Tbilisi → Stepantsminda/Kazbegi（marshrutka）
- Gergeti / Kazbek周辺ハイク
- Kazbegi → Tbilisi
- Tbilisi → Kars（国際バス。INFOBUS上で2026年のTbilisi–Kars route販売ページを確認）
- Kars + Ani遺跡
- Kars → Göreme（長距離バス）
- Cappadocia 2〜3日（徒歩ハイク主体、balloonはオプション）
- Göreme → Istanbul（夜行バス）
- Istanbul 4〜5日
- 10/29 Istanbul → Hong Kong → Zhuhai

## 現地交通の確認値
### Tbilisi ↔ Kazbegi
2026年現行案内では片道15〜20 GEL/人程度。
2人往復安全側 80 GEL ≒ 約4,900円。

### Tbilisi → Kars
INFOBUSで2026年のTbilisi→Kars route販売ページ自体を確認。
ただし10月分の確定料金はまだ表示期間外。
安全予算：2人 8,000〜14,000円。

### Kars → Göreme
2026年7月の販売例：
- 2,250 TRY/人
- 約12〜13時間
現在レート 1 TRY ≒ 3.31886 JPYとして、
2人 約14,900円。

### Göreme → Istanbul
2026年販売例の基準：約1,700 TRY/人、約8〜9時間。
2人 約11,300円。
夜行便なら宿1泊分を節約可能。

### Doğu Ekspresi案
TCDD公式システムに通常の「DOĞU EKSPRESİ」は現役列車として掲載されている。
ただし2026年10月分は販売前で、現時点で確定時刻・運賃を固定できない。
Touristic Doğu Ekspresiは2026-12-21以降なので10月には使えない。
→ Kars→Göremeバスを予算上の確定案とし、通常Doğu Ekspresi Kars→Ankaraが発売されたら「より若者旅らしい差替え候補」にする。

## 観光費
ベースは無料ハイク・街歩き重視。
Ani、Cappadociaの一部博物館/地下都市、Istanbulの有料施設を選択して：
**約30,000〜50,000円/2人**を予算化。

※Cappadocia balloonはベース予算から除外。実施する場合は大幅加算になるため別枠。

## Azerbaijanについて
- 2026-05-26にBaku→Tbilisi旅客列車が6年ぶりに運行した事実は確認。
- しかし現在の公式定期時刻表に安定掲載されていない。
- Baku–Tbilisi–Kars鉄道はインフラとして存在するが、2026年6月のGeorgian Railway発表は主に貨物・本格稼働に関するもの。
→ 現時点では旅程依存しない。
